# 09 · 基础算法思路

> 对应练习：`ex08_prefix_sum_diff.cpp`、`ex09_binary_search.cpp`、`ex10_enum_greedy.cpp`
> 六种最基本的解题套路。绝大多数入门题就是这六种的排列组合。

---

## 1. 模拟（Simulation）

**按题意把过程一步步做出来。** 没有算法，难点全在两点：**状态更新的顺序**和**边界**。

写法建议：把题目里的每个"对象"和"操作"都对应到一个变量/函数，然后照着题面逐条翻译。

```cpp
// 灯开关：n 盏灯初始关，m 次操作翻转 [l, r]
vector<int> a(n + 1, 0);                     // 下标从 1 开始，省掉换算
for (int op = 0; op < m; op++) {
    int l, r; cin >> l >> r;
    for (int i = l; i <= r; i++) a[i] ^= 1;  // 0/1 翻转用异或，一行搞定
}
```

**模拟前先算复杂度**：这题 `n, m ≤ 1000`，`m × n = 1e6`，能过。如果 `n, m ≤ 1e5`，`1e10` 就过不了，必须换差分（见第 4 节）。**"直接模拟能不能过"永远是第一个要判断的事。**

## 2. 枚举（暴力）

把所有候选都试一遍，用条件筛出合法解。

```cpp
// 枚举所有无序对
for (int i = 0; i < n; i++)
    for (int j = i + 1; j < n; j++)          // j 从 i+1 起：不重复、不含自身
        if (a[i] + a[j] == target) cnt++;

// 枚举子集（位掩码，n ≤ 20 才能用）
for (int mask = 0; mask < (1 << n); mask++)
    for (int i = 0; i < n; i++)
        if (mask >> i & 1) { ... }           // 第 i 个元素被选中
```

暴力的价值不只是"拿部分分"，它还是你的**正确答案参照物**：任何优化算法、任何贪心直觉，都应该和暴力在同一批随机数据上给出相同结果（这叫**对拍**，见第 14 章）。**先写暴力、再优化**是职业选手的标准流程。

枚举的设计原则：**枚举"不确定的东西"，用公式算出"确定的东西"**。比如枚举起点和终点、剩下的前缀和 O(1) 查——把三重循环降成两重。

---

## 3. 排序（见第 08 章）

这里只补充它在"思路"层面的作用：**排序是把无序问题变成有序问题的万能前置动作**。三个典型：

- 求第 k 大 / 最大间隔 → 排序后相邻比较
- 贪心 → 必须先按某个关键字排序
- 二分 → 必须有序

## 4. 前缀和与差分

互为逆运算的一对工具。

### 前缀和：快速**查**区间和

```cpp
vector<long long> p(n + 1, 0);                     // p[0] = 0 是设计的关键
for (int i = 1; i <= n; i++) p[i] = p[i-1] + a[i];
auto rangeSum = [&](int l, int r) { return p[r] - p[l-1]; };   // O(1) 查 [l, r]
```

二维版本（矩阵子块和）：

```cpp
// s[i][j] = 左上角 (1,1) 到 (i,j) 的矩形和
s[i][j] = s[i-1][j] + s[i][j-1] - s[i-1][j-1] + a[i-1][j-1];
// 查询 (r1,c1)-(r2,c2)
sum = s[r2][c2] - s[r1-1][c2] - s[r2][c1-1] + s[r1-1][c1-1];
```

`ex08` 里实测：`3×4` 矩阵 `(i+1)*(j+1)`，查 1-based 的 `(2,2)-(3,4)`，结果 **45**（= 4+6+8+6+9+12）。

**为什么要多开一行一列（下标 0 全 0）**：这样 `s[i-1][j]` 在 `i=1` 时天然等于 0，不用写边界特判。这个"多留一圈 0"的技巧在 DP、差分里反复出现。

### 差分：快速**改**区间

```cpp
// 每次给 [l, r] 整体加 v，只记录两个端点
d[l] += v; d[r+1] -= v;
// 全部操作完成后，做一次前缀和还原
for (int i = 1; i <= n; i++) { d[i] += d[i-1]; /* d[i] 就是最终值 */ }
```

`ex08` 实测：`n=6`，对 `[1,3]`、`[2,6]`、`[4,5]` 各加一次，还原得 `1 2 2 2 2 1`。

**差分是数组的"导数"，前缀和是"积分"**。看到"多次区间修改 + 最后一次性查询"就用差分；看到"多次区间查询 + 数据不变"就用前缀和。数组长度要开 `n+2`，因为 `d[r+1]` 在 `r = n` 时会写到 `n+1`。

**差分的经典应用**：区间加、统计区间覆盖次数、"公交车上下客"、二维差分（矩形加）。

## 5. 二分

### 二分查找（在有序序列里找位置）

```cpp
vector<int> a = {1, 3, 5, 5, 6, 8, 9};      // 前提：已排序
lower_bound(a.begin(), a.end(), 5)          // 第一个 >= 5 的位置  → 下标 2
upper_bound(a.begin(), a.end(), 5)          // 第一个 >  5 的位置  → 下标 4
upper_bound(...) - lower_bound(...)         // 5 出现了几次        → 2
binary_search(a.begin(), a.end(), 7)        // 存不存在            → 0 (false)
```

`ex09` 实测输出 `2 / 4 / 2 / 0`。用之前**一定要排序**，未有序序列上的二分结果是随机的。

### 二分答案（把"求最值"变成"判定可行性"）

适用条件三件套：**单调性**（答案越大越难满足 / 越小越容易）、**能验证**（给定一个候选值，能用 O(n) 判断行不行）、**要求最值**。

```cpp
// 求 floor(sqrt(x))，x 最大 1e12
long long lo = 0, hi = 2000000000LL;
while (lo < hi) {
    long long mid = lo + (hi - lo + 1) / 2;    // 向上取整
    if (mid <= x / mid) lo = mid;              // 满足 → 往更大的试
    else hi = mid - 1;                         // 不满足 → 收缩右边界
}
// 此时 lo == hi == 答案
```

`ex09` 实测：`x = 1e12` 得 **1000000**。注意 `x / mid` 而不是 `mid * mid <= x`——后者在 `mid` 接近 2e9 时溢出。

**只有两种二分模板，背死，别混搭：**

| 求什么 | mid 怎么取 | 满足时 | 不满足时 |
|---|---|---|---|
| 第一个满足条件的位置 | `(lo + hi) / 2` | `hi = mid` | `lo = mid + 1` |
| 最后一个满足条件的位置 | `(lo + hi + 1) / 2` | `lo = mid` | `hi = mid - 1` |

**死循环的唯一原因就是把这两行的取整和赋值配错了。** 检查方法：如果 `lo = mid`，`mid` 必须向上取整；如果 `hi = mid`，必须向下取整。

`mid = lo + (hi - lo) / 2` 而不是 `(lo + hi) / 2`：后者在 `lo, hi` 都接近 2e9 时溢出。养成写前者的习惯。

## 6. 贪心（Greedy）

**每一步都选当前看起来最好的，且做完不回头。** 成立的前提是"局部最优能推出全局最优"——这不是显然的，必须验证。

```cpp
// 活动选择：n 个区间，最多选多少个互不重叠的
sort(seg.begin(), seg.end(), [](const pair<int,int>& a, const pair<int,int>& b) {
    return a.second < b.second;            // 关键决策：按“结束时间”排，不是开始时间
});
int cnt = 0, last = -1;
for (auto& p : seg) if (p.first >= last) { cnt++; last = p.second; }
```

`ex10` 实测：输入 `7` 个区间，答案是 **4**。

**贪心怎么想**：先猜一个排序关键字（最早结束？性价比最高？最大先装？），然后**主动找反例**。上面这题如果按"开始时间最早"排，`ex10` 里会给出 3 而不是 4；按"区间最短"排同样能找到反例。找不到反例再证明（入门阶段" exchange argument 交换论证"够用：假设最优解第一步不选贪心选择，把它替换成贪心选择后解不会变差）。

**经典贪心模型**：活动选择、部分背包（按性价比）、最少线段覆盖、排队接水（短作业优先）、 Huffman（双队列/堆）、区间染色。

## 7. 六种思路的选型顺序

拿到题，按这个顺序问自己：

```
① 能不能直接模拟？算一下 n × 每步代价，能过就写。
② 能不能暴力枚举？同上，先拿到部分分再说。
③ 有没有"多次区间查/多次区间改"？→ 前缀和 / 差分
④ 有没有"有序"或"单调"？→ 二分
⑤ 有没有"每次选最优不后悔"的感觉？→ 排序 + 贪心（记得造反例验证）
⑥ 都不行，且要遍历所有方案 → 搜索（第 11 章）；有重叠子问题 → DP（第 13 章）
```

这个顺序本身就是"复杂度驱动"的：**先估规模，再选武器**。所以第 10 章的复杂度分析是这一切的前提。
