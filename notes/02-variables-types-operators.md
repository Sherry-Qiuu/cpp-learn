# 02 · 变量、数据类型与运算

> 对应练习：`ex01_types_io.cpp`、`ex02_control_flow.cpp`
> 核心一句话：**变量 = 有名字的内存；类型 = 这块内存多大 + 怎么解释它。**

---

## 1. 声明与初始化

```cpp
int a;              // 声明，未初始化 → 值是垃圾（函数内的局部变量）
int b = 0;          // 拷贝初始化，最常用
int c(0);           // 直接初始化，等价
int d{0};           // 列表初始化（C++11 起），会拒绝"窄化"，最安全
const int N = 100;  // 常量，声明后不能改，必须初始化
auto e = b + 1;     // 让编译器推导类型（e 是 int）
```

**为什么局部变量是垃圾值**：`int a;` 只是在栈上圈了一块内存，没人清零。全局变量和 `static` 变量会被自动初始化为 0。所以：

- 函数里的 `int sum;` 直接累加 → 结果随机。**必须 `int sum = 0;`**
- 数组：`int dp[1005] = {0};` 全部清零；`int dp[1005];` 在函数内是垃圾。
- `vector<int> v(100);` 会自动填 0，这是 `vector` 比裸数组安全的原因之一。

**`const` 要养成习惯**：只读的量（题里的 n、边界值、字符串参数）标 `const`，写错时编译器立刻拦你。

## 2. 内置类型一览

| 类型 | 字节数（本机 MinGW 64 位） | 取值范围 | 什么时候用 |
|---|---|---|---|
| `bool` | 1 | `true` / `false` | 条件、标记数组 |
| `char` | 1 | -128 ~ 127 | 单个字符 |
| `unsigned char` | 1 | 0 ~ 255 | 字节、位操作 |
| `short` | 2 | ±3.2 万 | 几乎不用 |
| `int` | 4 | 约 ±21.4 亿（-2³¹ ~ 2³¹-1） | **默认整数选择** |
| `unsigned int` | 4 | 0 ~ 42.9 亿 | 位运算、非负计数 |
| `long long` | 8 | 约 ±9.2 × 10¹⁸ | 求和、乘法、n > 2e9 |
| `float` | 4 | 约 7 位有效数字 | 一般不用 |
| `double` | 8 | 约 15~16 位有效数字 | **默认小数选择** |

三条经验规则：

1. **`int` 装得下不代表算得下**。`int x = 100000;` 没问题，但 `x * x` 是 1e10，超过 2^31，**溢出**得到负数。乘法前先想范围。
2. 需要 64 位整数就写 `long long`，字面量也要加后缀：`long long m = 1000000000000LL;`。不加 `LL` 的话 `1000000000000` 本身先按 `int` 解释（超出后是实现定义行为）。
3. 竞赛/算法题里，只要涉及**求和、求积、前缀和**，第一反应就是 `long long`。

**整数溢出是有符号未定义行为（UB）**：`int i = 2147483647; i = i + 1;` 编译器有权假设它不发生，优化后可能给你任何结果。无符号溢出则是**确定的回绕**（模 2ⁿ）。

## 3. 运算符与优先级

```
优先级从高到低（只列常用）：
  () [] -> .  ++ --（后置）
  ++ --（前置）  + -（取负）  !  ~  (类型)  *p  &x     ← 一元
  *  /  %
  +  -
  <<  >>
  <  <=  >  >=
  ==  !=
  &   ^   |
  &&
  ||
  ?:
  =  +=  -=  …                ← 赋值，最低
```

必须记住的三条：

```cpp
cout << (a == b) << "\n";   // 比较要加括号：<< 优先级高于 ==，不加括号会先算 (cout << a) == b
if (x = 5) { }              // 危险！这是赋值，永远为真。想比较写 ==
int y = 5 / 2;              // 2，整数除法直接截断（不是四舍五入）
int z = -5 / 2;             // -2，向 0 取整（C++11 起规定）
int r = -5 % 2;             // -1，余数符号跟被除数走
```

**`/` 和 `%` 的符号规则**：`(a/b)*b + a%b == a` 恒成立。所以判断"能不能整除"要写 `a % b == 0`，不要写 `a % b != 1`（负数会翻车）。

## 4. 类型转换

**隐式提升（自动，安全方向）**：小类型 → 大类型

```
bool/char/short ──> int ──> unsigned ──> long long ──> float ──> double
```

```cpp
int n = 7, m = 2;
double x = n + 0.5;          // n 被提升为 double，得 7.5
cout << n / m << "\n";       // 3  ← 两个操作数都是 int，先算再提升
cout << (double)n / m << "\n"; // 3.5 ← 先转一个，另一个自动跟着转
```

**关键陷阱**：`double y = n / m;` 得到的是 **3.0** 而不是 3.5。因为除法**先**在 int 世界里做完了，转换发生在赋值那一刻。要 3.5 必须**在除之前**转。

**显式转换（可能丢数据）**：

```cpp
(int)3.9          // 3，向 0 截断，不是四舍五入
static_cast<int>(3.9)   // 同上，C++ 风格，推荐——一眼能看出这里发生了转换
char c = 'a' - 32;      // 'A'，字符本质是整数
int digit = c - '0';    // 把字符 '7' 转成数字 7，处理字符串数字必用
```

**四舍五入**要手动做：`int r = (int)(x + 0.5);`（x 为负时不对，负数用 `round(x)`，来自 `<cmath>`）。

`static_cast<>` 优先于 C 风格 `(T)` 的理由：C 风格会悄悄做多种转换（包括去掉 `const`），出问题很难查；`static_cast` 只做数值转换和明确的指针向下转换，且**在代码里显眼的多**。

## 5. 字符与 ASCII

```cpp
char c = 'A';
cout << (int)c << "\n";      // 65
cout << (char)('a' - 'A') << "\n";  // 32
```

必须背下来的几条：

| 事实 | 用途 |
|---|---|
| `'0'` = 48，`'9'` = 57，连续 | `c - '0'` 把字符转数字；`d + '0'` 反过来 |
| `'A'` = 65，`'Z'` = 90，连续 | 字母表下标：`c - 'A'` 得 0~25 |
| `'a'` = 97，比大写大 32 | 大小写互换：`c ^= 32`（只在确定是字母时用） |
| `' '` = 32，`'\n'` = 10 | 跳过空白、行处理 |

判断与转换的正规写法（`<cctype>`）：`isdigit(c)`、`isalpha(c)`、`isupper(c)`、`tolower(c)`、`toupper(c)`。**优先用这些函数**，别手写 `c >= 'a' && c <= 'z'`（虽然也对，但可读性差且容易漏）。

## 6. 布尔与"真值"

```cpp
if (0)        // 假
if (5)        // 真 —— 非 0 即真
if (nullptr)  // 假
if (!v.empty())   // 推荐写法
if (v.size())     // 也能用，但不如上面清楚
```

一个常见错误：`if (a = 1)`（赋值）、`if (a == b == c)`（先算 `a==b` 得 bool，再和 c 比，几乎肯定不是你要的意思）。判断区间要写 `if (low <= x && x <= high)`，**不要写** `if (low <= x <= high)`——后者恒为真（`low<=x` 得 0/1，再和 high 比）。

## 7. 复合赋值与自增

```cpp
i += 2;   // 等价 i = i + 2，还有 -= *= /= %=
i++;      // 后置：表达式的值是加之前的 i
++i;      // 前置：表达式的值是加之后的 i
```

**单独成句时两者完全等价**，性能在现代编译器下也一样。只在"把 `i++` 的值用在更大表达式里"时才有区别——而那种写法本身就该避免（同一表达式里多次读写同一变量容易踩求值顺序问题）。建议：**独立语句一律写 `i++`，需要"先加再用"的值时才写 `++i`**。

## 8. 命名与常量

```cpp
#include <iostream>
using namespace std;

const int MOD = 1000000007;     // 取模题必备（写成 1e9+7 是 double，别这么干）
constexpr int MAXN = 100005;    // 编译期常量，可用于数组长度

int main() {
    int n = 5;                  // 循环变量用 i j k，临时量用有含义的名字
    long long sum = 0;
    int arr[MAXN] = {3, 1, 4, 1, 5};
    for (int i = 0; i < n; i++) sum = (sum + arr[i]) % MOD;
    cout << sum << "\n";        // 14
    return 0;
}
```

- 变量用小写加下划线（`max_len`、`left_sum`）或小驼峰（`maxLen`），**一个项目里保持一致**。
- 别用 `a`、`b`、`c`、`tmp` 一把抓；调试时你会认不出谁是谁。
- 魔法数字（`if (len == 11)`）要提成常量或加注释说明来历。
- **不要用单字母 `l`**（和数字 `1` 长得一样），也别用 `o`、`i` 之外的模糊名。
