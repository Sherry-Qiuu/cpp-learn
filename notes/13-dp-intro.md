## 1. 四步法（顺序不能颠倒）

```
① 状态定义：dp[...] 到底表示什么？必须能用一句中文说清楚。
② 转移方程：dp[i] 由哪些更小的状态算出来？（想"最后一步是怎么走的"）
③ 初始化：最小的那些状态直接给答案。
④ 答案位置：最终要的是 dp[n]？max(dp[i])？还是 dp[n-1][m-1]？
```

**① 是整个 DP 最难也最重要的一步。**定义含糊，转移就写不出来。常见两种定义方式：

- **"前 i 个"**：`dp[i]` = 考虑前 i 个元素时的答案 → 答案在 `dp[n]`
- **"以 i 结尾"**：`dp[i]` = 必须以 a[i] 结尾时的答案 → 答案在 `max(dp[i])`

LIS 只能用第二种（第一种无法转移），背包只能用"前 i 个 + 容量 j"。**做 DP 题时先把这两种定义各套一遍**，哪个能写出转移就用哪个。

## 2. 线性 DP

### 爬楼梯（一次 1 或 2 级）

```
定义：dp[i] = 爬到第 i 级的方案数
转移：最后一步要么跨 1 级（从 i-1 来），要么跨 2 级（从 i-2 来），互斥且完备
      dp[i] = dp[i-1] + dp[i-2]
初始化：dp[1] = 1, dp[2] = 2
答案：dp[n]
```

`ex13` 实测：`n = 10` → **89**。

### 网格路径（只能向右/向下）

```
定义：f[i][j] = 到 (i,j) 的路径数
转移：只能从上方或左方来 → f[i][j] = f[i-1][j] + f[i][j-1]
初始化：第一行、第一列全是 1（只有一条直路）
答案：f[r-1][c-1]
```

实测：3×7 → **28**（= C(8,2)，可以互相验证）。

### 打家劫舍（不能偷相邻）

```
定义：g[i] = 考虑到第 i 家时的最大金额
转移：偷第 i 家 → 只能从 i-2 转移；不偷 → 继承 i-1
      g[i] = max(g[i-1], g[i-2] + money[i])
答案：g[n-1]
```

实测：`{2,7,9,3,1}` → **12**（偷 7 和 3+… 实际最优是 2+9+1=12）。

注意 `i < 2` 时的边界，本仓库用 `(i ? g[i-1] : 0, i >= 2 ? g[i-2] : 0)` 处理，也可以用 `g.assign(n+2, 0)` 在前面补两个 0，让下标整体后移——**后者更清晰，推荐**。

## 3. 背包：DP 的分水岭

`n` 件物品，容量 `C`，每件重量 `w[i]`、价值 `v[i]`。

### 二维版本（先把逻辑想清楚）

```
定义：dp[i][c] = 前 i 件物品、容量 c 时的最大价值
转移：第 i 件要么不放，要么放（放得下的前提 c >= w[i]）
      dp[i][c] = max(dp[i-1][c], dp[i-1][c - w[i]] + v[i])
初始化：dp[0][*] = 0
答案：dp[n][C]
```

### 压缩成一维（滚动数组）

`dp[i][...]` 只依赖 `dp[i-1][...]`，所以一维数组够用——但**内层容量必须逆序**：

```cpp
vector<int> dp(C + 1, 0);
for (int i = 0; i < n; i++)
    for (int cap = C; cap >= w[i]; cap--)          // ★ 逆序
        dp[cap] = max(dp[cap], dp[cap - w[i]] + v[i]);
```

`ex13` 实测的逐件填表过程（`w={2,3,4,5}`、`v={3,4,5,6}`、`C=8`）：

| 处理完 | cap 0 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
|---|---|---|---|---|---|---|---|---|---|
| 初始 | 0 | 0 | 0 | 0 | 0 | 0 | 0 | 0 | 0 |
| 物品1 (2,3) | 0 | 0 | 3 | 3 | 3 | 3 | 3 | 3 | 3 |
| 物品2 (3,4) | 0 | 0 | 3 | 4 | 4 | 7 | 7 | 7 | 7 |
| 物品3 (4,5) | 0 | 0 | 3 | 4 | 5 | 7 | 8 | 9 | 9 |
| 物品4 (5,6) | 0 | 0 | 3 | 4 | 5 | 7 | 8 | 9 | **10** |

**为什么逆序？** `dp[cap]` 要读的是"上一行"（还没考虑第 i 件时）的 `dp[cap - w[i]]`。逆序遍历时 `cap - w[i]` 还没被本轮更新，读到的正是旧值 → 每件物品**最多用一次**，这就是 01 背包。

正序遍历则 `dp[cap - w[i]]` 已经是"本轮更新过"的值，意味着第 i 件可能已经被用过，再算一次就重复了 → 每件物品**可以用无限次**，那就是**完全背包**。

> **一个循环方向的差别，区分了两种完全不同的问题。** 这是 DP 里最值钱的一条知识，务必亲手在 `ex13` 里改一下顺序，看答案从 10 变成多少（完全背包的答案是 12）。

## 4. LIS：必须用"以 i 结尾"

```
定义：d[i] = 以 a[i] 结尾的最长严格上升子序列长度
转移：枚举前一个元素是谁 → d[i] = max(d[j] + 1)，其中 j < i 且 a[j] < a[i]
初始化：所有 d[i] = 1（每个元素自己就是长度 1 的序列）
答案：max(d[i])   ← 不是 d[n-1]！
```

实测：`{10,9,2,5,3,7,101,18}` → **4**（如 2,5,7,101）。

**答案位置是 `max`，不是最后一个**：因为最长序列不一定以最后一个元素结尾。这是"以 i 结尾"定义必然带来的后果，也是初学者丢答案的常见位置。

O(n²) 之外还有 O(n log n) 的贪心+二分做法（维护 `tails` 数组，对每个 `a[i]` 做 `lower_bound`），见 `ex13` 的选做部分。

## 5. DP 的五个高频错误

| 错误 | 症状 | 修法 |
|---|---|---|
| 初始化错 | 样例都对，答案偏大/偏小 | 手动填出最小的那张表，逐个核对 |
| 遍历方向错 | 背包答案偏大（物品重复用） | 01 背包逆序，完全背包正序 |
| 答案位置错 | 取 `dp[n]` 其实是 `max(dp)` | 由状态定义决定，见第 1 节 |
| 求最值时 `dp` 初值取 0 | 无解被当成"价值 0" | 求 max 且可能无解 → 初值 `-INF`；方案数 → 0，但 `dp[0] = 1` |
| 溢出 | 大样例答案错 | 方案数类一律 `long long` 或边算边取模 |

**方案数 vs 最值的初始化差异**要特别记：路径计数里 `dp[起点] = 1`（"什么都不做也是一种方案"），最值类 `dp[0] = 0` 或 `-INF`。把 `dp[0]` 写成 0 是背包题满分变 0 分的原因，反过来把 `dp[0]` 写成 1 会让最值题多算一条不存在的方案。

## 6. 怎么练

按这个顺序，每类做 2~3 题：

1. 线性：爬楼梯 → 打家劫舍 → 最大子段和（`dp[i] = max(a[i], dp[i-1] + a[i])`）
2. 网格：不同路径 → 最小路径和 → 数字三角形
3. 背包：01 背包（模板）→ 完全背包 → 恰好装满的变形（初值改 `-INF`）→ 方案数版（`+=` 代替 `max`）
4. 子序列：LIS → LCS（二维）→ 编辑距离
5. 区间 DP：石合并、回文划分（`dp[l][r]` 由更短的区间推出）

**做题流程永远是**：先写"暴力枚举/递归"，再发现重复子问题，加 `memo` 数组变记忆化，最后按依赖顺序改写成循环。这条路径比"凭空想转移方程"可靠得多，也正是第 05 章→本章的连接点。
